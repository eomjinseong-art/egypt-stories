# 이집트이야기 (Egypt Stories)

이집트 역사가 어렵게 느껴지는 어른을 위해, 한국어로 짧게 정리한 정적 사이트입니다. 영어 제목은 짧게 두고, 설명은 한국어로 씁니다.

나두 — 나의 모든 일상을 AI와 함께

자매 사이트 [나두신화](https://nadoo-myth.vercel.app)는 그리스·로마 신화, [로마이야기](https://rome-stories.vercel.app)는 로마 역사, [그리스이야기](https://greece-stories.vercel.app)는 그리스 역사를 다룹니다. 이집트이야기는 나일강의 왕국, 파라오, 신전, 그리고 그 신화·로마·그리스와 맞닿는 지점만 잇습니다.

## 메뉴

- **홈** `/` — 여섯 시대, 모든 갈래, 자매 사이트
- **시대** `/origins` — 선왕조 → 고왕국·중왕국·신왕국 → 후기 → 프톨레마이오스
- **지도** `/map` — 나일강, 상·하이집트, 멤피스, 테베, 알렉산드리아, 기자, 카르나크, 왕가의 계곡
- **파라오** `/rulers`, `/rulers/[slug]` — 길을 잡는 열두 사람
- **가족관계도** `/family-tree` — 신화, 18왕조, 19왕조, 프톨레마이오스. 불확실한 혈연은 점선
- **클레오파트라와 로마** `/cleopatra` — 프톨레마이오스 왕조, 카이사르, 안토니우스. 로마 쪽은 로마이야기로 잇습니다
- **신** `/gods` — 이집트 신 개요. 그리스·로마와 겹치는 이름만 나두신화로 연결. `/myth-links`는 여기로 넘어갑니다
- **일상** `/daily` — 범람, 농사, 글자, 신전, 내세
- **유적** `/monuments` — 피라미드, 신전, 무덤. 전설과 발굴을 구분
- **전쟁** `/wars`, `/wars/[slug]` — 힉소스, 카데시, 바다 민족, 아시리아, 페르시아, 알렉산드로스, 로마
- **관련 영화** `/movies` — 미이라, 클레오파트라, 이집트 왕자, 출애굽 영화. 어디가 창작인지 구분. 불법 영상 링크 없음
- **출처** `/sources`

글의 꼴은 한 줄 요약, 핵심 세 가지, 펼치는 「조금만 더」입니다. 전설과 역사는 배지로 나눕니다.

## 개발

```bash
npm ci
npm run dev
npm run build
```

Next.js 15 (App Router) · React 19 · Tailwind CSS v4 · TypeScript. 페이지는 빌드 때 정적으로 생성됩니다.

콘텐츠는 `data/`에 있습니다. `NEXT_PUBLIC_SITE_URL`의 기본값은 `https://egypt-stories.vercel.app`입니다.

## 적는 기준

고대 기록의 이름과 위치만 밝히고, 없는 인용문을 만들지 않습니다. 현대 책의 문장을 번역해 붙이지 않습니다. 영화 제목은 실제 개봉 제목을 쓰고, 작품을 볼 수 있는 불법 사이트는 안내하지 않습니다. 출애굽 영화는 신앙의 이야기로 적고, 특정 파라오의 연대기와 확인된 것처럼 겹치지 않습니다.
